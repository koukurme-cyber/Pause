# Changelog

## 0.1.0 — 2026-09-20

- Создана кодовая база «Паузы».
- Добавлен лаконичный зелёно-светлый UI на Compose.
- Добавлен реальный список launchable-приложений.
- Телефон и сообщения зафиксированы как всегда доступные.
- Реализованы выбор белого списка и длительности.
- Добавлен обязательный экран перепроверки критичных приложений.
- Добавлено подтверждение длинным удержанием.
- Добавлен активный экран и таймер.
- Добавлены DEV-предохранители.
- Реальный системный blocker намеренно отложен.
- Белый список blocker-слоя автоматически дополняется пакетами текущих Phone/SMS-приложений и самой «Паузы».
- Добавлена GitHub Actions-сборка debug APK без зависимости от Gradle Wrapper.
- Build-конфигурация приведена к AGP 9.4 / built-in Kotlin.
