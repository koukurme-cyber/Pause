# Пауза — зафиксированные правила продукта

Дата фиксации: 2026-09-20

## Базовый сценарий

1. Пользователь выбирает приложения, которые останутся доступными.
2. «Телефон» и «Сообщения» всегда доступны и не имеют переключателя отключения.
3. Пользователь выбирает длительность Паузы.
4. Перед запуском показывается отдельное предупреждение: после старта список нельзя изменить и Паузу нельзя закончить досрочно.
5. Предупреждение явно напоминает проверить критичные бытовые приложения: банк, карты/навигацию, проездные/транспорт, такси, домофон/пропуск/парковку, билеты/документы.
6. Запуск подтверждается длинным удержанием, чтобы исключить случайное включение.
7. Во время активной Паузы обычной кнопки «выключить» нет.
8. По окончании срока доступ восстанавливается автоматически.

## Безопасность разработки

- На основном телефоне до отдельного этапа не используем Device Owner / Lock Task.
- Первые сборки работают с `NoopPauseBlocker` и не могут блокировать устройство.
- Debug-сборка имеет аварийное завершение тестовой Паузы.
- Debug-сессия ограничивается максимум 10 минутами.
- Системный строгий blocker подключается отдельным слоем после проверки UI и сборки.
- При сбое будущий blocker должен быть fail-open: ошибка не должна оставлять устройство заблокированным.

## Не входит в MVP

- Блокировка YouTube Shorts.
- Блокировка Instagram Reels.
- Статистика использования.
- Несколько профилей/расписаний.
