# Пауза — Android v0.1

Первая безопасная кодовая версия интерфейса приложения «Пауза».

## Что уже работает

- Kotlin + Jetpack Compose.
- Реальный список запускаемых приложений на устройстве.
- Выбор белого списка.
- «Телефон» и «Сообщения» вынесены в отдельный неотключаемый блок.
- Длительность: 30 минут / 1 / 2 / 4 часа.
- Отдельный экран предупреждения перед запуском.
- Напоминание проверить банк, карты, транспорт, такси, домофон/пропуск, парковку, билеты и документы.
- Запуск только длинным удержанием 2 секунды.
- Активный экран с обратным отсчётом и без пользовательской кнопки отмены.
- Выбранные приложения сохраняются между запусками.
- Активная сессия переживает обычное закрытие/повторный запуск приложения.

## Важно: v0.1 пока НЕ блокирует другие приложения

`PauseBlocker` специально реализован как `NoopPauseBlocker`.

Это сделано намеренно: сначала проверяем дизайн, навигацию, список приложений, сохранение и таймер на реальном телефоне. Никаких AccessibilityService / Device Owner / Lock Task в эту сборку не включено, поэтому она физически не может запереть основной телефон.

## DEV-предохранители

В debug-сборке:

- максимальная длительность тестовой Паузы — 10 минут;
- на активном экране есть явная кнопка `DEV: завершить тестовую Паузу`;
- системная блокировка отсутствует.

Эти элементы завязаны на `BuildConfig.DEBUG` и не должны попадать в production-UX.

## Следующий этап

После проверки интерфейса подключить отдельный Android blocker-слой. Делать это поэтапно:

1. AccessibilityService только для обнаружения запрещённого приложения + fail-open.
2. Отдельный экран блокировки.
3. Проверка Phone/SMS и критичных системных экранов.
4. Аварийный DEV bypass.
5. Только после этого — эксперимент со строгим Device Owner / Lock Task на отдельном тестовом устройстве.

## Сборка

Открыть корневую папку в Android Studio. Проект настроен на:

- AGP 9.4.0
- Gradle 9.6.0
- Kotlin/KGP 2.2.10 (встроенный Kotlin AGP 9.x)
- Compose BOM 2026.09.00
- compileSdk 37
- targetSdk 36
- minSdk 26

Для локальной сборки нужен установленный Android SDK соответствующей версии.

Также добавлен `.github/workflows/android-debug.yml`: после загрузки проекта в GitHub он собирает debug APK через Gradle 9.6.0 и публикует его как Actions artifact. Это основной воспроизводимый путь сборки на текущем этапе.
